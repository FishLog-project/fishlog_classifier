## 합격 기준 (MVP)

| 지표 | 목표 | 비고 |
|---|---|---|
| 전체 Top-3 정확도 | **90% 이상** | 서비스의 진짜 기준 |
| 전체 Top-1 정확도 | 75% 이상 | 참고용 |
| 흔한 종(easy) Top-1 | 90% 이상 | 돌돔·참돔·광어·배스 등 |
| 어려운 종(hard) Top-3 | **90% 이상** | 붕어·잉어·감성돔·우럭·볼락 |
| 종별 recall 하한 | 60% 이상 | 이하면 데이터 재수집 대상 |
| `기타` recall | 80% 이상 | 비물고기를 물고기로 우기지 않아야 함 |
| `기타` 오탐율 | 10% 이하 | 진짜 물고기를 `기타`로 밀어내면 UX가 망가진다 |

Top-1이 낮아도 Top-3가 높으면 **합격**이다. 사용자가 후보 중에서 고르는 구조이기 때문.

**`기타` 클래스는 어종 지표와 분리해서 본다.** 전체 정확도는 24종만으로도 한 번, 25클래스 전체로도 한 번 계산한다 — 섞으면 `기타` 성능이 어종 성능을 가린다.

## 집중 점검 대상

`config.CONFUSABLE_GROUPS` 6그룹은 별도로 뽑아본다:

| 그룹 | 구분 단서 (검수·오류분석 시 참고) |
|---|---|
| 붕어 ↔ 잉어 | 잉어는 입가에 **수염 2쌍**, 붕어는 없음 |
| 우럭 ↔ 볼락 | 우럭(조피볼락)이 더 크고 짙은 갈색, 볼락은 눈이 상대적으로 큼 |
| 감성돔 ↔ 벵에돔 | 감성돔은 은회색에 옆줄 무늬, 벵에돔은 더 검고 둥근 체형 |
| 고등어 ↔ 전갱이 ↔ 삼치 | 전갱이는 꼬리 쪽 **모비늘(zeigo)**, 고등어는 등쪽 물결무늬 |
| 숭어 ↔ 농어 | 농어는 등지느러미 가시 뚜렷·입이 큼 |
| 메기 ↔ 동자개 | 동자개는 노란 몸에 검은 반점, 메기는 흑갈색 |

두 종이 서로 **대칭적으로** 헷갈리면 → 데이터 부족 문제.
한쪽으로만 쏠리면 → 클래스 불균형 또는 해당 종의 라벨 오염 문제.

## 임계값 튜닝 (`uncertain`)

- val셋에서 임계값을 0.2~0.8로 훑으며 (정확도, 거부율)을 기록한다.
- 기준: **거부율 10% 이하를 유지하면서 Top-3 정확도가 최대**인 지점.
- 너무 높게 잡으면 "다시 촬영" 요구가 잦아 UX가 나빠지고, 낮게 잡으면 엉뚱한 후보를 자신 있게 보여준다.
- softmax는 과신하는 경향이 있으므로, 확률을 사용자에게 % 로 노출할 거면 temperature scaling으로 보정한다 ([decisions.md C-2](decisions.md)).

## 목표 미달 시 대응 순서

1. `worst_cases/` 확인 → **라벨 오염**이면 데이터 정제 (가장 흔한 원인)
2. 해당 종 이미지 추가 수집 (특히 실사용 유사 사진)
3. 증강·해상도 조정, 백본 교체
4. 그래도 안 되면 → 해당 종을 Top-3에서만 살리는 것으로 타협
5. **클래스 삭제는 최후 수단.** 삭제하면 순서가 바뀌므로 반드시 맨 뒤에서 제거하거나 전체 재학습 + labels.json 재생성

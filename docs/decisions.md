## B. 지금 답이 필요한 것 (블로커)

### B-1. 공모전 마감일이 언제인가 ⛔
- 2주 타임라인을 실제 마감에 맞춰 조정해야 한다. 특히 데이터 보강 재학습(Phase 4→3 되돌이)에 며칠을 쓸 수 있는지가 갈린다.
- **필요한 답**: 마감일, 그리고 제출물에 무엇이 포함되는가(모델? 데모 앱? 발표자료?)

### B-2. 모델 서버를 어디에 배포할 것인가
- 후보: Cloud Run(요청당 과금·콜드스타트 있음) / Railway·Fly.io(간단) / EC2·오라클 무료티어(상시).
- ONNX CPU 추론이면 512MB~1GB RAM으로 충분. 콜드스타트가 UX에 미치는 영향 확인 필요.
- **필요한 답**: 앱 백엔드가 이미 어디에 떠 있나? 같은 곳에 붙이는 게 편하다.

### B-3. 24종에 없는 어종을 잡았을 때 앱 UX
- 예: 향어, 학꽁치, 우럭볼락… Top-3에 정답이 아예 없다.
- 앱에서 **"목록에서 직접 선택"** 대안 경로가 필요하다(모델과 무관하게 앱 백엔드 담당).
- **필요한 답**: 이 UX가 앱에 있는가? 없다면 누가 만드는가?

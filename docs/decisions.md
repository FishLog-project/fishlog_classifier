### ~~B-2. 모델 서버를 어디에 배포할 것인가~~ → **A로 이동 (2026-08-22)**
**AWS EC2에 컨테이너로 상시 구동.** 앱 백엔드가 중계하고 모델 서버는 내부에만 노출한다.
